# 星际先锋 · Stellar Vanguard

[微信小程序] 对话驱动的太空探索叙事游戏，明日方舟风格美术。

## 游戏简介

你醒来了。通讯频道静默了四百三十七天。

你是先锋舰队第七远征组的成员。三个月前，舰队与母港失联。你只剩下一艘伤痕累累的飞船，和三颗坐标指向的未知星球。

探索、选择、生存。在深空中找到你的答案。

## 游戏特色

- **对话驱动叙事** — 分支对话与选择影响剧情走向
- **三颗独特星球** — 锈蚀星 X-47、晶渊星 XC-119、寂语星 WD-013，每颗星球有独立场景与剧情
- **多结局系统** — 根据你的选择走向不同结局：「过客」「桥梁」「掠夺者」「理智崩溃」「星际共鸣」
- **体力制探索** — 行动消耗体力，随时间自动恢复
- **天文科普** — 探索中穿插真实的科学知识卡片
- **深空遗响** — 解锁 lore 收集品，拼凑故事全貌

## 星球

| 星球 | 代号 | 描述 |
|------|------|------|
| 锈蚀星 | X-47 | 氧化铁覆盖的废弃星球，有微弱信号 |
| 晶渊星 | XC-119 | 冰层下晶体共振的神秘星球 |
| 寂语星 | WD-013 | 声波永不停歇的回声星球 |

## 操作说明

- **点击对话** — 推进剧情
- **选择行动** — 每个选择消耗不同体力
- **返回星图** — 可在各星球间切换
- **深空遗响** — 查看已解锁的 lore 收集品

## 技术栈

- **平台**：微信小程序
- **语言**：JavaScript + WXML + WXSS
- **状态管理**：自定义 GameEngine（体力/能量/理智/信号）
- **脚本引擎**：自定义对话脚本系统（队列 + 状态机）
- **美术**：明日方舟风格手绘角色 + CSS 视觉装饰

## 项目结构

## 变量体系

| 变量 | 说明 |
|------|------|
| STA (Stamina) | 体力，行动消耗，每5分钟恢复1点 |
| NRG (Energy) | 能源，通过探索获取 |
| SAN (Sanity) | 理智，关键选择会影响 |
| SIG (Signal) | 信号强度，解锁特殊剧情 |

## 结局列表

- **过客** — 默认结局
- **桥梁** — 与原住民建立联系
- **掠夺者** — 驱散原住民，获取能源
- **理智崩溃** — SAN 归零
- **星际共鸣**（隐藏）— 获得原住民信任并共享核心
